# Texture Assets

The textures in `default/` are development placeholders used for local visual testing while the engine, atlas, and resource-pack systems are evolving.

Some placeholder textures are imported from external Minecraft-compatible resource packs, including Classic Faithful 64x Jappa. They are not final ZigCraft art, and this project does not claim ownership of third-party texture assets.

Before public release or redistribution, replace placeholder textures with original assets or assets with license terms that are explicitly compatible with the project.

When adding or replacing textures:
- Keep source attribution and license information with the asset pack.
- Prefer stable project-facing filenames in `default/` so block mappings do not need one-off code changes.
- Use `scripts/process_textures.sh` for high-resolution PBR source material when applicable.
